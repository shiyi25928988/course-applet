第八章 电能与磁
🎯学习目标
  • 掌握电功和电功率的概念及计算公式
  • 理解焦耳定律（电流的热效应）及其应用
  • 了解奥斯特实验（电流的磁效应）和安培定则
  • 了解电磁铁、电磁继电器、电动机的工作原理
  • 了解法拉第电磁感应现象和发电机原理
  • 了解电能的输送和电磁波在无线电通信中的应用
💡 本章核心思想：电与磁是相互联系的——电流可以产生磁场（电生磁），变化的磁场可以产生电流（磁生电）。电能与机械能可以通过电磁现象相互转化，这是现代电气文明的基础。

8.1 电功率

电功

电流做的功叫做电功。电流做功的过程是将电能转化为其他形式能的过程（如热能、光能、机械能）。

W = UIt

其中 U 为电压（V），I 为电流（A），t 为通电时间（s）。

单位：焦耳（J）。生活中常用单位：千瓦时（kW·h，俗称"度"）。

📐 单位换算：1 kW·h = 1000 W × 3600 s = 3.6×10⁶ J。家庭电能表（千瓦时计）计量的是用电器消耗的电能。

电功率

电功率：电流在单位时间内所做的功，表示电流做功的快慢。电功率越大，做功越快。

P = W/t = UI

单位：瓦特（W），常用 kW（千瓦）、mW（毫瓦）。1 kW = 1000 W。

推导公式（纯电阻电路中）：P = I²R = U²/R

额定功率：用电器在额定电压下工作时的功率（铭牌上标的功率）。

实际功率：用电器在实际电压下工作时的功率。

⚖️ 额定功率 vs 实际功率
• 当 U实 = U额 时，P实 = P额，用电器正常工作；
• 当 U实 > U额 时，P实 > P额，用电器易损坏（如灯泡过亮烧断）；
• 当 U实 < U额 时，P实 < P额，用电器不能正常工作（如灯泡偏暗）。
• 灯泡的亮度由实际功率决定，实际功率越大，灯越亮。
用电器额定电压额定功率（约）能量转化
家用电灯（LED）220 V5~20 W电能→光能+内能
电视机220 V100~200 W电能→光能+声能+内能
电饭锅220 V800~1200 W电能→内能
空调220 V1000~2000 W电能→机械能+内能
家用电热水器220 V1500~3000 W电能→内能

焦耳定律

电流通过导体产生的热量跟电流的平方成正比，跟导体的电阻成正比，跟通电时间成正比。

Q = I²Rt

这是英国物理学家焦耳通过大量实验得出的规律。对于纯电阻电路，电能全部转化为热能，此时 W = Q = UIt = I²Rt。

🔥 电流热效应的应用与防止
• 应用：电热水器、电饭锅、电烙铁、电熨斗、电热毯等——利用电流热效应制热。
• 防止：电视机散热孔、电脑风扇、电动机散热片——防止热量积聚损坏设备。

8.2 电流的磁场

奥斯特实验（电流的磁效应）

1820年，丹麦物理学家奥斯特发现：通电导线下方的小磁针会发生偏转。这表明通电导线周围存在磁场，磁场方向与电流方向有关。

🔬 奥斯特实验的意义：第一次证实了电与磁之间的联系——电可以生磁。这开启了电磁学的研究，为后来法拉第发现电磁感应（磁生电）奠定了基础。

实验现象：当电流方向改变时，小磁针偏转方向也改变，说明磁场方向与电流方向有关。

通电螺线管与安培定则

通电螺线管的磁场与条形磁铁的磁场相似，外部磁感线从N极出来回到S极，内部从S极指向N极。

安培定则（右手螺旋定则）：用右手握住螺线管，让四指弯曲方向与螺线管中电流方向一致，则拇指所指的方向就是螺线管的N极。

螺线管的磁极方向由电流方向决定；磁性强弱由电流大小和线圈匝数决定。

🧲 通电螺线管磁场

电磁铁

电磁铁：内部带有铁芯的通电螺线管。插入铁芯后，铁芯被磁化，磁场大大增强。

电磁铁的磁性强弱影响因素：

  • 电流大小：匝数一定时，电流越大，磁性越强；
  • 线圈匝数：电流一定时，匝数越多，磁性越强；
  • 有无铁芯：有铁芯时磁性显著增强。
✅ 电磁铁的三大优点：
① 磁性有无可控——通断电控制；
② 磁性强弱可调——改变电流大小；
③ 极性可换——改变电流方向。

电磁继电器

电磁继电器：利用电磁铁控制工作电路通断的自动开关，相当于一个"用低电压、弱电流控制高电压、强电流"的开关。

结构：电磁铁、衔铁、弹簧、触点。当控制电路通电时，电磁铁吸合衔铁，工作电路接通。

🛡️ 电磁继电器的应用价值：
• 安全隔离：操作人员只需接触低压控制电路，避免接触高压危险电路；
• 远程控制：可在远距离通过弱电流控制大功率设备；
• 自动控制：配合温度、光敏、声控等传感器实现自动化（如恒温箱、自动报警装置）。

电动机原理

电动机原理：通电导体在磁场中受力运动（电能→机械能）。磁场对电流有力的作用，力的方向与电流方向、磁场方向都有关。

⚙️ 换向器的作用：直流电动机中，换向器（两个半圆铜环）能在线圈每转过平衡位置时，自动改变线圈中的电流方向，使线圈受力方向始终一致，从而保证线圈持续转动。没有换向器，线圈只能转到平衡位置就停下。

应用：电风扇、洗衣机、电动车、电钻、工业机械等。

8.3 电能的获得和输送

法拉第电磁感应

1831年，英国物理学家法拉第发现了电磁感应现象：闭合电路的一部分导体在磁场中做切割磁感线运动时，导体中就会产生感应电流。这是"磁生电"的现象。

感应电流方向与导体运动方向和磁场方向有关（两者任一改变，电流方向改变；两者同时改变，电流方向不变）。

感应电流大小与磁场强弱、导体运动速度、切割磁感线的有效长度有关。

💡 法拉第电磁感应的伟大意义：实现了"磁生电"，使人类大规模获得电能成为可能，奠定了发电机的基础，开启了电气时代。

发电机原理

发电机原理：电磁感应（机械能→电能）。线圈在磁场中旋转，做切割磁感线运动，产生感应电流。

电动机原理：通电导体在磁场中受力（电能→机械能）。两者是可逆的能量转化过程。

对比项发电机电动机
原理电磁感应通电导体在磁场中受力
能量转化机械能→电能电能→机械能
电路中作用电源用电器
是否需要电源不需要外部电源需要外部电源

交流电：方向和大小做周期性变化的电流。我国交流电频率为50 Hz，周期 T = 0.02 s，每秒方向改变 100 次。

电能的输送

采用高压输电可以减少电能在输电线上的损失。

📐 高压输电原理：
由 P = UI 可知，输送功率 P 一定时，电压越高，电流越小。
输电线上损失功率 P损 = I²R，电流减小为原来的 1/n，损失功率就减小为原来的 1/n²。
因此采用高压输电可大幅降低线路损耗。

变压器：用于改变交流电的电压（仅适用于交流电）。升压变压器用于输电端（升压以减小电流），降压变压器用于用户端（降压以安全使用）。

⚠️ 注意：变压器不能改变直流电的电压。家庭用户电压为 220 V，工业动力电压为 380 V。

8.4 无线电波和无线电通信

电磁波

电磁波是变化的电流在空间中传播形成的。它可以在真空中传播，不需要介质（与声波不同！）。传播速度等于光速：

c = 3×10⁸ m/s

波长λ、频率f、波速c的关系：

c = λf

电磁波谱（按频率从低到高）：

电磁波类型频率范围主要应用
无线电波<3×10⁹ Hz广播、电视、通信
微波3×10⁹~3×10¹¹ Hz雷达、卫星通信、微波炉
红外线3×10¹¹~3×10¹⁴ Hz遥控、夜视、加热
可见光3×10¹⁴~7.5×10¹⁴ Hz照明、视觉
紫外线7.5×10¹⁴~3×10¹⁶ Hz杀菌消毒、验钞
X射线3×10¹⁶~3×10¹⁹ Hz医学透视、安检
γ射线>3×10¹⁹ Hz医学治疗、工业探伤
📡 电磁波的应用：广播、电视、手机通信、Wi-Fi、蓝牙、雷达、卫星导航、微波炉、医用X光等。电磁波频率越高，穿透能力越强，但能量也越大。
⚠️ 易错点辨析：
• 声波 vs 电磁波：声波传播需要介质（真空不能传声），电磁波传播不需要介质（可在真空中传播）。
• 发电机 vs 电动机：发电机是"磁生电"（无电源），电动机是"电生力"（需电源）。
• 奥斯特实验 vs 法拉第实验：奥斯特实验证明电生磁，法拉第实验证明磁生电。

📝 章节练习题

1电功率的计算公式是____。
✅ B。P=W/t=UI，电功率等于电压乘以电流。在纯电阻电路中还可推导为 P=I²R=U²/R。
2焦耳定律的表达式是____。
✅ B。焦耳定律Q=I²Rt，电流通过导体产生的热量与电流的平方成正比，与电阻成正比，与通电时间成正比。
3发电机的工作原理是____。
✅ B。发电机原理是电磁感应（磁生电），机械能转化为电能。电动机原理是通电导体在磁场中受力（电生力），电能转化为机械能。
41千瓦时（度）等于____焦耳。
✅ B。1 kW·h = 1000 W × 3600 s = 3.6×10⁶ J。家庭电能表就是以"度"（kW·h）为单位计量电能的。
5电磁波在真空中的传播速度是____。
✅ C。电磁波在真空中传播速度等于光速 c = 3×10⁸ m/s，且不需要介质（与声波不同）。
6关于通电螺线管的磁极方向，下列说法正确的是____。
✅ C。通电螺线管的磁极方向由电流方向决定，用右手螺旋定则（安培定则）判断；磁性强弱由电流大小和线圈匝数共同决定。
7一盏标有"220V 60W"的白炽灯，正常工作时的电流约为____。
✅ A。由 P = UI 得 I = P/U = 60W / 220V ≈ 0.27 A。注意正常工作时即额定电压下工作，功率等于额定功率。
8高压输电的目的是____。
✅ B。高压输电时，由 P=UI 知输送功率一定时电压越高电流越小，而线损 P损=I²R 与电流平方成正比，故电流越小损失越小。
