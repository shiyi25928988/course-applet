🏋️ 力学压轴

📐 力学概念细化（做题前先过一遍）

压力 ≠ 重力

F压 = G 只在"水平面静止 + 只受重力和支持力"时成立，斜面上不成立。

受力面积 S 取两物体的实际接触面：叠放时取较小者的上表面，而不是大物体的表面积。

叠放题逐层列式：上层压下层 F = G上；下层压地面 F = G上 + G下。

p = F/S （S 必须是真正受力的那块面积）

求浮力的四把钥匙

① 称重法：F浮 = G − F示；② 阿基米德：F浮 = ρ液gV排；

③ 平衡法：漂浮、悬浮时 F浮 = G；

④ 沉底陷阱：沉底时容器底有支持力 N，F浮 = G − N < G，此时绝不能再令 F浮 = G！

液面变化只看 V排

一切液面升降 = 排开液体总体积的变化：Δh = ΔV排 / S容（S 是容器截面积）。

漂浮时 V排 = m/ρ水；沉底浸没时 V排 = V物 = m/ρ物。

ρ物 > ρ水的物体从漂浮改沉底 → V排 减小 → 液面下降。

漂浮 V排/V物 = ρ物/ρ液

杠杆动态平衡

F₁L₁ = F₂L₂；力臂是支点到力的作用线的垂直距离，不是到作用点的连线。

均匀棒的重力作用在中点；把支点选在未知力所在处，可以"消掉"那个未知力。

最小动力的方向：与杆垂直、力臂最长（等于杆长）。

机械效率的本性

η = W有/W总 = Gh/(Fs)，滑轮组中 s = nh（n 为承重绳段数）。

η 只看"额外功占多少"：物重越大 η 越大；动滑轮越重、摩擦越大 η 越小。

η 与绳的绕法、提升高度、提升速度无关；η 恒小于 1。

1叠放正方体压强★★★

实心正方体 A 的边长为 0.2m，密度为 2×10³kg/m³；实心正方体 B 的边长为 0.4m，密度为 0.5×10³kg/m³。将 A 叠放在水平桌面上的 B 的正中央。求：

(1) A 对 B 的压强；

(2) B 对桌面的压强。（g = 10N/kg）

答案：(1) 4000Pa；(2) 3000Pa
解析：
为什么先算重力再算压强？因为固体传力"传力不传压"，叠放问题必须逐层算压力。
(1) V_A = 0.2³ = 8×10⁻³m³，m_A = ρV = 2000×8×10⁻³ = 16kg，G_A = 160N
A 对 B 的压力 F₁ = G_A = 160N，受力面积为两者中较小的接触面 S_A = 0.2×0.2 = 0.04m²
p₁ = F₁/S_A = 160/0.04 = 4000Pa
(2) V_B = 0.4³ = 0.064m³，m_B = 500×0.064 = 32kg，G_B = 320N
B 对桌面压力 F₂ = G_A + G_B = 480N，S_B = 0.16m²
p₂ = 480/0.16 = 3000Pa
易错点：(1) 中受力面积不能用大正方体的上表面积 0.16m²，压力只作用在 A 与 B 的实际接触面 0.04m² 上。
2木块载石块的液面变化★★★

底面积为 100cm² 的柱形容器中盛有足量的水。质量为 300g 的木块上放一质量为 100g 的石块，整体漂浮在水面上。现将石块取下轻轻放入水中（石块密度为 2.5g/cm³，沉底，水未溢出）。求液面高度变化了多少？向哪个方向变化？

答案：液面下降 0.6cm
解析：
核心思路：液面变化只看"排开水的总体积"的变化。
① 石块在木块上时，整体漂浮：F浮 = G总，V排₁ = (m木+m石)/ρ水 = 400g/1(g/cm³) = 400cm³
② 石块放入水中后：
  木块单独漂浮：V排木 = m木/ρ水 = 300cm³
  石块沉底（浸没）：V排石 = V石 = m石/ρ石 = 100/2.5 = 40cm³
  V排₂ = 300 + 40 = 340cm³
③ ΔV排 = 400 - 340 = 60cm³ → 液面下降，Δh = ΔV排/S = 60/100 = 0.6cm
为什么石块落水后总排水量变小？漂浮时石块"靠浮力托起全部重力"，排开的水重等于 m石；沉底后水只托起它排开体积那么大（40cm³），其余靠容器底支持。差值 (100-40)cm³ 就是液面下降的原因。
3斜靠木棒的杠杆动态平衡★★★

一根均匀木棒 AB 长 1m、重 30N，A 端支在地上，B 端用竖直细绳吊起，棒保持水平。求：

(1) 细绳对 B 端的拉力；

(2) 若在距 A 端 25cm 处挂一个 20N 的重物，绳的拉力变为多少？

(3) 重物挂在距 A 端多远处，绳的拉力恰好为 18N？

答案：(1) 15N；(2) 20N；(3) 0.15m
解析：
为什么以 A 为支点列力矩平衡？A 处地面支持力未知，以它为转轴可消去未知量。
(1) 重心在棒中点（距 A 0.5m）：F×1 = 30×0.5 → F = 15N
(2) 20×0.25 + 30×0.5 = F×1 → 5 + 15 = F → F = 20N
(3) 20×d + 30×0.5 = 18×1 → 20d = 3 → d = 0.15m
检验：d=0.15m 在棒长范围内，合理。
4滑轮组机械效率随物重变化★★★

用由 3 段绳子承担重物的滑轮组（不计绳重和摩擦）匀速提升重 240N 的物体，绳自由端拉力为 100N。求：

(1) 动滑轮的总重；

(2) 此时滑轮组的机械效率；

(3) 若改提重 480N 的物体，拉力和机械效率变为多少？

答案：(1) 60N；(2) 80%；(3) 180N，约 88.9%
解析：
(1) 不计绳重和摩擦时 F = (G物 + G动)/n：100 = (240 + G动)/3 → G动 = 60N
(2) 设物体上升 h，绳端移动 s = 3h
η = W有/W总 = Gh/(F·3h) = 240/(100×3) = 240/300 = 80%
为什么 h 可以约掉？机械效率只与力和绳的段数有关，与提升高度无关。
(3) G动不变：F' = (480+60)/3 = 180N；η' = 480/(180×3) = 480/540 ≈ 88.9%
结论：同一滑轮组，提起的物重越大，有用功占比越大，机械效率越高——这是中考选择题高频考点。
5细线拴木块：剪断前后★★★

体积为 500cm³、密度为 0.6×10³kg/m³ 的木块 A 用细线拴在容器底部，完全浸没在水中。求：

(1) 细线对木块的拉力；

(2) 剪断细线，木块静止后露出水面的体积。（ρ水 = 1.0×10³kg/m³，g = 10N/kg）

答案：(1) 2N；(2) 200cm³
解析：
(1) G = ρ木gV = 600×10×5×10⁻⁴ = 3N；F浮 = ρ水gV排 = 1000×10×5×10⁻⁴ = 5N
浸没且被线拉住，三力平衡：F浮 = G + T → T = 5 - 3 = 2N
为什么 T = F浮 - G？线对木块的拉力向上（木块想上浮），两个向上的力与重力平衡。
(2) 剪断后 F浮 > G → 上浮 → 最终漂浮。漂浮时 F浮' = G = 3N
V排' = F浮'/(ρ水g) = 3/10⁴ = 3×10⁻⁴m³ = 300cm³
V露 = 500 - 300 = 200cm³（即露出总体积的 2/5）
规律：漂浮时 V排/V物 = ρ物/ρ液。
6"图像题"：缓慢压入水中★★★

（文字描述图像）用弹簧测力计悬挂一实心长方体金属块，缓慢竖直浸入水中。下表面刚接触水面时，测力计示数为 4N；随着浸入深度增大，示数均匀减小；当下表面距水面 5cm（即恰好完全浸没）后继续下移，示数保持 3N 不变。求：

(1) 金属块完全浸没时受到的浮力；

(2) 金属块的体积和底面积；

(3) 金属块的密度。（ρ水 = 1.0×10³kg/m³，g = 10N/kg）

答案：(1) 1N；(2) 100cm³，20cm²；(3) 4×10³kg/m³
解析：
(1) 未浸入时示数 = G = 4N；浸没后示数 = G - F浮 = 3N → F浮 = 1N
(2) V = V排 = F浮/(ρ水g) = 1/(10³×10) = 10⁻⁴m³ = 100cm³
恰好浸没时下表面深度 5cm 就是长方体的高 h = 5cm
S = V/h = 100/5 = 20cm²
(3) m = G/g = 0.4kg，ρ = m/V = 0.4/10⁻⁴ = 4×10³kg/m³
读图要领："示数不变"的起点对应"恰好浸没"，那一时刻的深度就是物体的竖直高度——这是图像题中隐藏的几何条件。

⚡ 电学压轴

📐 电学概念细化（做题前先过一遍）

第一步永远是认电路

只有一条电流路径 = 串联（电流相同、电压分）；出现分叉再汇合 = 并联（电压相同、电流分）。

开关通断会改变结构：动手画出两种开关状态下的等效电路图，是解双开关压轴题最值钱的基本功。

动态电路四步法

① 认串并联结构 → ② 盯住不变量（电源 U、定值电阻 R）→ ③ 看变化量（滑片移动、开关通断）→ ④ 出结论：

串联：R₂ ↑ → I ↓ → 定值电阻分压 ↓，变阻器分压 ↑；

并联：各支路互不影响，干路 I = 各支路电流之和。

三个功率公式怎么选

P = UI 普适；同电流（串联）比功率用 P = I²R；同电压（并联）比功率用 P = U²/R。

灯的亮暗只由实际功率决定，和额定功率没有直接关系——AC 两选项陷阱都由此而来。

额定值 vs 实际值

R 是导体自身的属性，恒定不变（除非题目特别说明）。

实际功率随电压变化：P实 = (U实/U额)² × P额——电压降 10%，功率降约 19%。

"正常发光"三个字 = U、P、I 三个额定值同时锁定，全部变成已知量。

电表的安全线

电压表内阻极大、并联接入、读数不影响电路；电流表内阻≈0、必须串联，并联在电阻两端 = 短路。

中考常问"滑动变阻器的最小允许值"——由 I ≤ 电流表量程 或 U₁ ≤ 电压表量程 列不等式解出。

拖动滑片改变 R₂： R₂ = 10Ω

红点是定向移动的电流，速度代表电流大小；右侧电压条高度表示 U₁、U₂ 的大小（仅示意）。把 R₂ 滑到 0 和 20Ω，验证第 7 题的两个极端状态。

7串联动态电路：电流与电压的范围★★★

电源电压 6V 保持不变，定值电阻 R₁ = 10Ω 与滑动变阻器 R₂（最大阻值 20Ω）串联。电压表接在 R₁ 两端，电流表串联在电路中。求滑动变阻器滑片从一端滑到另一端的过程中：

(1) 电流表示数的变化范围；

(2) 电压表示数的变化范围。

答案：(1) 0.2A ~ 0.6A；(2) 2V ~ 6V
解析：
串联电路 I = U/(R₁+R₂)，R₂ 增大 → I 减小 → U₁ = IR₁ 减小（R₁ 两端电压）
① R₂ = 0 时（滑片在最左端）：I最大 = 6/10 = 0.6A，U₁最大 = 6V
② R₂ = 20Ω 时：I最小 = 6/(10+20) = 0.2A，U₁最小 = 0.2×10 = 2V
易错提醒：电流范围是 0.2~0.6A，不能颠倒；电压表测 R₁ 而不是电源，所以它跟随电流同向变化，而 R₂ 两端电压是反向变化（4V~0V）。
8并联动态电路：干路电流的范围★★★

电源电压 6V 不变，R₁ = 12Ω 与滑动变阻器 R₂ 并联，R₂ 的可调范围为 6Ω~24Ω。电流表接在干路上。求电流表示数的变化范围。

答案：0.75A ~ 1.5A
解析：
并联各支路互不影响：I₁ = U/R₁ = 6/12 = 0.5A（恒定）
I₂ = U/R₂：
① R₂ = 24Ω 时：I₂最小 = 6/24 = 0.25A → 干路 I最小 = 0.5 + 0.25 = 0.75A
② R₂ = 6Ω 时：I₂最大 = 6/6 = 1A → 干路 I最大 = 0.5 + 1 = 1.5A
关键思想：并联中一条支路的电阻变化不影响另一条支路的电流——这与串联"牵一发而动全身"形成鲜明对比，是判断动态电路的第一步：先辨认串、并联。
9两灯串联谁更亮★★★

灯 L₁ 标有"220V 25W"，灯 L₂ 标有"220V 100W"。将它们串联接入 220V 电路中（设灯丝电阻不变）。问：

(1) 哪盏灯更亮？说明理由；

(2) 两灯能否正常发光？

答案：(1) L₁（25W 灯）更亮；(2) 不能，两灯均变暗
解析：
(1) R₁ = U额²/P额₁ = 220²/25 = 1936Ω；R₂ = 220²/100 = 484Ω，R₁ > R₂
串联电流处处相等，实际功率 P = I²R 与 R 成正比 → P₁实 > P₂实 → L₁ 更亮
(2) 串联分压：U₁:U₂ = R₁:R₂ = 4:1，U₁ = 176V、U₂ = 44V，都达不到 220V
且 R总 = 1936+484 = 2420Ω，I = 220/2420 ≈ 0.09A，两灯实际功率都远小于额定功率 → 都变暗，不能正常发光
陷阱：凭生活经验认为"100W 的灯更亮"是错的——亮暗看实际功率，串联时额定功率小的灯反而更亮；若改成并联，则 L₂ 更亮（P = U²/R，电压相同，R 小者功率大）。
10串联分压保护电阻★★★

一盏标有"6V 3W"的小灯，要接到 9V 电源上正常发光，需串联一个电阻 R。求：

(1) R 的阻值；

(2) R 消耗的电功率和整个电路的效率（灯消耗功率占总功率的比例）。

答案：(1) 6Ω；(2) 1.5W，约 66.7%
解析：
灯正常发光 → 通过灯的电流为额定电流 I = P额/U额 = 3/6 = 0.5A
串联电路电流处处相等 → 通过 R 的电流也是 0.5A
U_R = U总 - U灯 = 9 - 6 = 3V
(1) R = U_R/I = 3/0.5 = 6Ω
(2) P_R = U_R·I = 3×0.5 = 1.5W；P总 = 3 + 1.5 = 4.5W，效率 = 3/4.5 ≈ 66.7%
思路梳理："正常发光"三个字意味着灯两端电压就是 6V、功率就是 3W——把已知量全部钉死，剩下的只是串联分压。
11双开关电路综合★★★

电源电压不变，R₁、R₂ 为定值电阻。只闭合开关 S 时，R₁ 与 R₂ 串联，电流表示数为 0.2A，R₁ 两端电压为 4V；再闭合开关 S₁ 后（R₂ 被短接），电流表示数变为 0.6A。求：

(1) 电源电压和 R₁ 的阻值；

(2) R₂ 的阻值；

(3) 两种状态下 R₁ 消耗的电功率之比。

答案：(1) 12V，20Ω；(2) 40Ω；(3) 9:1
解析：
(1) S₁ 闭合后 R₂ 被短路，电路中只有 R₁：U = I'R₁ = 0.6R₁
只闭合 S 时：U₁ = IR₁ = 0.2R₁ = 4V → R₁ = 20Ω，U = 0.6×20 = 12V
(2) 串联时总电阻 R = U/I = 12/0.2 = 60Ω → R₂ = 60 - 20 = 40Ω
(3) P = I²R，R₁ 不变：P₁'/P₁ = (I'/I)² = (0.6/0.2)² = 9，即 P₁' : P₁ = 9 : 1
解题顺序：双开关题先分别画出两种开关状态下的"等效电路图"，再各列一个方程联立求解——画等效图是这类压轴题最重要的基本功。
12电能表测电功率 + 实际电压问题★★★

小明家的电能表标有"3000r/(kW·h)"。只让电热水壶工作，5 分钟内电能表转盘转了 150 转。求：

(1) 电热水壶的实际电功率；

(2) 若电热水壶的额定电压为 220V、额定功率为 600W（电阻不变），当时实际电压只有 200V，求它的实际功率（结果保留整数）。

答案：(1) 600W；(2) 约 496W
解析：
(1) 消耗电能 W = 150/3000 = 0.05kW·h = 1.8×10⁵J
t = 5min = 300s → P = W/t = 1.8×10⁵/300 = 600W
为什么正好等于额定功率？说明当时电压正常，这也是自检答案合理性的手段。
(2) R = U额²/P额 = 220²/600 ≈ 80.7Ω（电阻由壶本身决定，不变）
P实 = U实²/R = 200²/80.7 ≈ 496W
另一种更快的算法：P实 = (U实/U额)² × P额 = (200/220)²×600 = 100/121×600 ≈ 496W
规律：电阻不变时，电功率与电压的平方成正比——电压降 10%，功率降约 19%。

🔥 热学·声光压轴

📐 热学·声光概念细化（做题前先过一遍）

热平衡方程的方向感

Q放 = Q吸：高温物体写 (t高 − t)，低温物体写 (t − t低)，正负号写反必出错。

解出的 t 必在两初温之间，且偏向"m·c 大"的一边——算完先拿这两条检验。

效率的分子分母要认主

烧水：η = Q吸/Q放；热机：η = W有用/Q放。

分母永远是燃料完全燃烧放出的总热量 Q放 = mq（或 Vq），分子是"真正被利用的那部分"。

题给"效率 40%"，就是 Q吸（或 W有）= 0.4 × Q放。

平面镜成像三件套

等大、等距、虚像；光路可逆。

测视力本质：用镜子把短房间的光路"折"一遍——人到像的距离 = 人到镜 + 表到镜。

画图口诀：像与物关于镜面对称，先定像的位置，光路自动清晰。

回声测距的两个方向

声音走的是"鸣笛点 → 山崖 → 听到回声点"的折线：

迎面行驶 L = (s声 + s车)/2；远离行驶 L = (s声 − s车)/2。

先画出两个时刻的车、崖位置图再列式，比背公式更可靠。

13热平衡方程：冷热水混合★★★

将 3kg、80℃ 的热水与 2kg、10℃ 的冷水在绝热容器中混合，不计热量损失。求混合后的共同温度。（c水 = 4.2×10³J/(kg·℃)）

答案：52℃
解析：
热平衡：Q放 = Q吸
c水·m热·(t热 - t) = c水·m冷·(t - t冷)
3×(80 - t) = 2×(t - 10)（比热容约掉了，因为是同种物质）
240 - 3t = 2t - 20 → 260 = 5t → t = 52℃
检验：52℃ 介于 10℃ 与 80℃ 之间，且更靠近质量大的一侧（3kg 热水），合理。
易错点：等式左边用 (高温 - t)、右边用 (t - 低温)，方向写反就会解出荒谬结果；算完务必检验温度范围。
14燃气灶烧水的热效率★★★

用天然气灶把 2kg、20℃ 的水加热到 70℃。[c水 = 4.2×10³J/(kg·℃)，天然气热值 q = 4.2×10⁷J/m³] 求：

(1) 水吸收的热量；

(2) 若该灶的效率为 40%，需要消耗多少立方米的天然气？

答案：(1) 4.2×10⁵J；(2) 0.025m³
解析：
(1) Q吸 = c水mΔt = 4200×2×(70-20) = 4.2×10⁵J
(2) 效率 η = Q吸/Q放 → Q放 = Q吸/η = 4.2×10⁵/0.4 = 1.05×10⁶J
V = Q放/q = 1.05×10⁶/4.2×10⁷ = 0.025m³
为什么除以 0.4 而不是乘？水只吸收了燃气放出热量的 40%，放出的总热量必然比吸收的多，所以 Q放 = Q吸/η > Q吸。用"结果应比 Q吸 大"来检验方向是否搞反。
15汽车发动机的热机效率★★★

一辆汽车以额定功率 60kW 在平直公路上匀速行驶 1h，共消耗汽油 15kg。求这辆汽车发动机的效率。（汽油热值 q = 4.6×10⁷J/kg）

答案：约 31.3%
解析：
有用功（输出机械能）：W有 = Pt = 60×10³ × 3600 = 2.16×10⁸J
燃料完全燃烧放热：Q放 = mq = 15 × 4.6×10⁷ = 6.9×10⁸J
η = W有/Q放 = 2.16×10⁸/6.9×10⁸ ≈ 31.3%
理解效率分母分子：热机效率 = 做有用功的那部分能量 ÷ 燃料完全燃烧释放的总能量。本题耗油量与功率是独立给的两个条件，不能再用 P=Fv 反推——先分清哪些量是"有用"，哪些是"总账"。
16平面镜检查视力★★★

检查视力时要求人与视力表的像相距 5m。现室内平面镜挂在墙上，视力表挂在人身后的墙上，视力表到平面镜的距离为 3m，人面向平面镜且距平面镜 2m。问人看到的视力表的像距人多远？是否符合 5m 的检查要求？

答案：像距人 5m，符合要求
解析：
平面镜成像特点：像与物到镜面的距离相等。
视力表距镜 3m → 它的像在镜后 3m 处。
人在镜前 2m 处面向镜子 → 人到像的距离 = 2 + 3 = 5m ✓
应用原理：这就是小房间测视力的标准方案——用平面镜把 3m 深的房间"折"出 5m 的光路。画光路图（人—镜—像三点一线）是解此类题的关键，切勿把"人到视力表的实物距离"（仅 1m）当成检查距离。
17回声测距：运动着的汽车★★★

汽车以 20m/s 的速度朝正前方的山崖匀速行驶，司机鸣笛后 2s 听到回声。已知声音在空气中传播速度为 340m/s。求鸣笛时汽车距山崖多远。

答案：360m
解析：
设鸣笛时车距崖 L。
2s 内：声音传播路程 s声 = 340×2 = 680m；汽车前进 s车 = 20×2 = 40m
声音走的路线是"鸣笛处 → 崖 → 听到回声处"：s声 = L + (L - s车)
680 = 2L - 40 → L = 360m
易错点：听到回声时车已前进 40m，声音的终点不是鸣笛处！画出"车—崖"两个时刻的位置示意图，一秒看穿。若车远离崖行驶，则 s声 = L + (L + s车)，结果不同——方向是这类题的隐藏变量。
18平面镜转角：让阳光水平照射★★★

清晨，太阳光与水平地面成 30° 角射向地面。要用一块平面镜把太阳光反射后沿水平方向射出，平面镜镜面应与水平地面成多大的角度？

答案：75°（或 105°，两种对称放置均可）
解析：
入射光与水平面成 30°，反射光沿水平方向 → 入射光线与反射光线的夹角 θ = 180° - 30° = 150°
法线是入射光线与反射光线夹角的平分线 → 反射角 = 入射角 = 150°/2 = 75°
镜面与法线垂直 → 镜面与"入反射光线夹角的平分面"垂直，镜面与水平面的夹角 = 90° - ? 分两步算：
取反射光沿水平方向的情况：法线与水平面的夹角 = 90° - 75° = 15°，故镜面与水平面夹角 = 90° - 15° = 75°（法线朝上倾斜）；若反射光改为沿另一侧水平方向射出，由对称性得镜面与水平面成 105°，即等效于 75° 的另一种摆放。
方法总结：这类题口诀是"光路转折角的一半是反射角，镜面与法线垂直"——先画出入射线和反射线，两条线的夹角折半得法线，再补镜面，角度自然出来。
