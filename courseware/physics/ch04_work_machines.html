第四章 机械和功
🎯学习目标
  • 理解动能和势能的概念及其相互转化
  • 掌握功的计算公式 W=Fs，理解做功的两个必要因素
  • 掌握功率的概念及公式 P=W/t=Fv
  • 掌握杠杆、滑轮等简单机械的原理
  • 理解功的原理：使用任何机械都不省功；理解机械效率 η=W有用/W总

4.1 机械能

动能

物体由于运动而具有的能叫做动能。一切运动的物体都具有动能。

影响动能大小的因素：质量和速度。

  • 质量相同时，速度越大，动能越大
  • 速度相同时，质量越大，动能越大
  • 速度对动能的影响更大（与速度的平方成正比）
Ek = ½mv²

实例：运动的汽车、飞行的子弹、流动的水。

重力势能

重力势能：物体由于被举高而具有的能。

影响因素：质量和高度。

  • 质量相同时，高度越大，重力势能越大
  • 高度相同时，质量越大，重力势能越大
Ep = mgh

实例：被举高的重锤、高山上的石头。

弹性势能

弹性势能：物体由于发生弹性形变而具有的能。

影响因素：形变程度（弹性形变越大，弹性势能越大）和材料本身的性质。

实例：拉长的弹簧、拉弯的弓、压缩的弹簧、撑杆跳的撑杆。

📌 动能和势能的相互转化
动能和势能可以相互转化。在只有重力或弹力做功的情况下（忽略摩擦和空气阻力），机械能的总量保持不变，这就是机械能守恒。
  • 滚摆下落：重力势能 → 动能（加速下落）
  • 滚摆上升：动能 → 重力势能（减速上升）
  • 单摆运动：最高点势能最大，最低点动能最大
  • 自由落体：重力势能不断转化为动能

4.2 机械功

功的概念

如果一个力作用在物体上，物体在这个力的方向上移动了一段距离，就说这个力对物体做了功。

做功的两个必要因素：

  • 作用在物体上的力（F）
  • 物体在力的方向上移动的距离（s）
W = Fs

单位：焦耳（J），1J = 1N·m。表示用1N的力使物体在力的方向上移动1m所做的功。

⚠️ 三种不做功的情况
情况说明实例
有力无距离有力作用在物体上，但物体没有移动推车未推动、举重物停在空中
有距无力物体移动了距离，但在此方向上没有力作用踢出的足球在水平地面滑行（重力不做功）
力与距离垂直力的方向与物体运动方向垂直提水桶水平行走、圆周运动的向心力
💡 功的实质
做功的过程就是能量转化的过程。做了多少功，就有多少能量发生转化。功是能量转化的量度。

功率

功率：表示做功快慢的物理量。单位时间内所做的功叫做功率。

P = W / t

单位：瓦特（W），1W = 1J/s。常用单位：千瓦（kW）、兆瓦（MW）。1kW = 1000W。

推导公式：当力与运动方向相同时，由 W=Fs 可得：
P = W/t = Fs/t = Fv
其中 v 是物体运动的平均速度。该公式常用于汽车牵引力功率的计算。

实例：人步行功率约70W，跑步约几百瓦；轿车发动机功率几十千瓦到上百千瓦。

4.3 简单机械

杠杆

杠杆：在力的作用下能绕固定点转动的硬棒。杠杆可以是直的，也可以是弯的。

杠杆五要素：

要素定义
支点（O）杠杆绕着转动的固定点
动力（F₁）使杠杆转动的力
阻力（F₂）阻碍杠杆转动的力
动力臂（L₁）支点到动力作用线的距离
阻力臂（L₂）支点到阻力作用线的距离

杠杆平衡条件（杠杆原理）：动力×动力臂 = 阻力×阻力臂

F₁L₁ = F₂L₂

三类杠杆：

类型力臂关系力的大小特点实例
省力杠杆L₁ > L₂F₁ < F₂省力费距离撬棒、铡刀、瓶起子、手推车
费力杠杆L₁ < L₂F₁ > F₂费力省距离镊子、筷子、钓鱼竿、缝纫机踏板
等臂杠杆L₁ = L₂F₁ = F₂不省力不费力天平、定滑轮

滑轮

定滑轮：轴固定不动的滑轮。

  • 实质：等臂杠杆
  • 特点：不省力，但可以改变力的方向
  • 关系：F = G，s = h（拉力移动距离等于物体上升距离）

动滑轮：轴随物体一起移动的滑轮。

  • 实质：动力臂为阻力臂2倍的杠杆
  • 特点：省一半力，但不能改变力的方向
  • 关系：F = G/2（不计摩擦和滑轮重），s = 2h

滑轮组：定滑轮和动滑轮组合而成。

  • 特点：既可以省力，又可以改变力的方向
  • 关系：F = G/n，s = nh（n 为承担物重的绳子段数）
F = G/n （n为承担物重的绳子段数）
绳子段数 n 的判断方法：直接与动滑轮相连的绳子段数。注意：绳子最后从定滑轮引出时不计入 n，从动滑轮引出时计入 n。

4.4 功的原理与机械效率

功的原理

使用任何机械都不省功。即使用机械时，人们所做的功，都不会少于直接用手所做的功。

💡 功的原理的理解
虽然不省功，但机械可以省力、省距离或改变力的方向，给人们带来方便。
理想机械（无摩擦）：W机 = W手（使用机械做的功 = 直接用手做的功）
实际机械（有摩擦）：W机 > W手（使用机械做的功 > 直接用手做的功）

机械效率

使用机械做功时，对人们有用的功叫做有用功（W有用）；并非我们需要但又不得不做的功叫做额外功（W额外）；有用功与额外功之和叫做总功（W总）。

W总 = W有用 + W额外

机械效率：有用功跟总功的比值。符号 η。

η = W有用 / W总 × 100%
⚠️ 注意事项
① 由于额外功的存在（机械自重、摩擦等），机械效率总小于1（总小于100%）；
② 机械效率没有单位，是一个比值；
③ 提高机械效率的方法：减小摩擦、减轻机械自重、增加物重。

常见机械效率：滑轮组约50%~70%，杠杆可达90%以上。

📝 章节练习题

1做功的两个必要因素是____。
✅ B。做功两个必要因素：作用在物体上的力，和物体在力的方向上移动的距离。两者缺一不可。
2功率是表示____的物理量。
✅ B。功率表示做功快慢，P=W/t，单位瓦特（W）。
3杠杆平衡条件是____。
✅ B。杠杆平衡条件（杠杆原理）：动力×动力臂=阻力×阻力臂，即F₁L₁=F₂L₂。
4关于功的原理，正确的说法是____。
✅ B。使用任何机械都不省功。机械效率总小于100%。
5机械能包括____。
✅ B。机械能包括动能和势能（重力势能和弹性势能）。
6下列情况中，力对物体做了功的是____。
✅ D。A有力无距离（不做功）；B提力方向向上，水桶水平移动，力与距离垂直（不做功）；C足球踢出后脚不再对球施力（有距无力）；D力和距离同时满足且方向一致，做了功。
7用10N的水平拉力拉着重50N的物体在水平面上前进了4m，拉力做的功和重力做的功分别是____。
✅ B。拉力做的功 W=Fs=10N×4m=40J；重力方向竖直向下，物体水平移动，重力与运动方向垂直，重力不做功，即0J。
8关于机械效率，下列说法正确的是____。
✅ C。机械效率η=W有用/W总，额外功越小，W总越接近W有用，η越高。A混淆了功率与效率；B没考虑总功；D实际机械效率总小于100%。
