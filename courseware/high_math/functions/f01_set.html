1.1 集合的概念

三大特性（每个都要会"用"而不只是"背"）：
① 确定性：给定一个集合，任何元素"属于/不属于"有且只有一个答案。"个子高的同学"不是集合，"身高>180cm 的同学"才是。
② 互异性：同一集合中元素互不相同——解出参数后必须回代检验。
③ 无序性：{1,2,3} 与 {3,2,1} 是同一个集合。
集合的表示法：
① 列举法：{1, 2, 3}；② 描述法：{x | x² − 3x + 2 = 0}；③ 图示法（Venn 图 / 数轴）；④ 区间法：[1, 5)、(−∞, +∞)

常见数集字母：
记号含义易错点
ℕ自然数集（含 0）0 ∈ ℕ
ℕ* 或 ℕ₊正整数集0 ∉ ℕ*
ℤ整数集−2 ∈ ℤ
ℚ有理数集½ ∈ ℚ，π ∉ ℚ
ℝ实数集√2 ∈ ℝ
⚠ 描述法的"代表元"辨析（高频考点）：
集合本质
A = {x | y = x²}数集＝全体实数 x 的函数取值范围 = ℝ
B = {y | y = x², x∈ℝ}数集＝函数值域 = [0, +∞)
（注意 A 与 B 不同！）
C = {(x, y) | y = x²}点集＝抛物线上的所有点
代表元是什么元素（x、y 还是点 (x,y)），集合就是"什么集合"。

1.2 集合间的基本关系

关系与记号：
子集 A ⊆ B：A 的元素全部在 B 中（含相等）；真子集 A ⫋ B：A ⊆ B 且 A ≠ B
相等 A = B ⇔ A ⊆ B 且 B ⊆ A
空集 ∅ 是任何集合的子集，是非空集合的真子集（解题先想"有没有可能是空集"）

元素个数公式：若 A 中有 n 个元素，则 ——
子集 2ⁿ 个 ； 真子集 2ⁿ−1 个 ； 非空真子集 2ⁿ−2 个
例：A = {1, 2, 3}，n = 3 → 子集 8 个，真子集 7 个，非空真子集 6 个。

1.3 集合的运算 + 德摩根律

交集 A ∩ B = {x | x ∈ A 且 x ∈ B}　　并集 A ∪ B = {x | x ∈ A 或 x ∈ B}
补集 ∁ᴜA = {x | x ∈ U 且 x ∉ A}　　德摩根律：∁ᴜ(A∪B) = ∁ᴜA ∩ ∁ᴜB，∁ᴜ(A∩B) = ∁ᴜA ∪ ∁ᴜB
💡 三组最重要的等价关系（高考选择题秒杀用）：
数学命题等价的集合说法
A ∩ B = AA ⊆ B
A ∪ B = BA ⊆ B
A ∩ B = ∅A、B 无公共元素（可解端点问题）
口诀："交半取小、并半取大"（对连续型集合在数轴上）。

1.4 常用逻辑用语

充分 / 必要条件的判断：
p ⇒ q（由 p 能推出 q）：p 是 q 的充分条件，q 是 p 的必要条件
p ⇔ q：充要条件

记忆口诀："箭头指着谁，谁就是必要；箭头的出发点就是充分。"

条件集合化（秒杀技巧）：

设 p、q 对应的数集分别为 P、Q：

关系集合解释
p 是 q 的充分不必要条件P ⫋ Q（P 是 Q 的真子集）
p 是 q 的必要不充分条件Q ⫋ P
p 是 q 的充要条件P = Q
p 既不充分也不必要P、Q 互不包含
"小范围推出大范围"——记住它，参数取值范围的反向问题（"求 r 使它是充分不必要条件"）就变成子集求参数。
⚠ "命题的否定" ≠ "否命题"：
设原命题"若 p，则 q"：
① 否命题（既否条件又否结论）：若 ¬p，则 ¬q
② 命题的否定（只否整个命题）：¬(若 p 则 q) ⇔ 若 p，则 ¬q
量词否定的翻转规则：∀ ↔ ∃，结论同时取反。
¬(∀x∈M, p(x)) = ∃x∈M, ¬p(x)　　¬(∃x∈M, p(x)) = ∀x∈M, ¬p(x)

1.5 典型例题精讲

例 1【空集陷阱】 ★★★

设 A = {x | x² − 3x + 2 = 0}，B = {x | ax − 1 = 0}。若 B ⊆ A，求实数 a 的值。


A = {1, 2}。B 可能为空集吗？——第一步必须先讨论它是否为空集！
① a = 0 时，ax − 1 = 0 无解，B = ∅ ⊆ A ✓
② a ≠ 0 时，B = {1/a}。要 1/a ∈ {1, 2} → a = 1 或 a = ½
综上：a = 0 或 a = 1 或 a = ½
⚠ 易错：漏掉 a = 0（B = ∅ 这一支）——B 中方程"是不是一次方程"取决于 a，B 可能是空集。

例 2【互异性检验】 ★★★

已知 A = {1, 3, x}，B = {1, x²}，且 B ⊆ A。求 x。


B ⊆ A → x² ∈ {1, 3, x}，分类：
① x² = 1 → x = ±1。x = 1 时 A = {1, 3, 1} ✗（违反互异性）；x = −1 时 A = {1, 3, −1} ✓，B = {1} ✓
② x² = 3 → x = ±√3 ✓（A = {1, 3, ±√3}，B = {1, 3}）
③ x² = x → x = 0（x = 1 舍，同上违反互异性）
综上：x = −1 或 x = 0 或 x = ±√3
💡 方法总结：含参数集合问题"三步曲"——解参数 → 代入检验互异性 → 写答案。

例 3【条件集合化】 ★★★

"x > 1" 是 "x > 2" 的什么条件？


联想到集合：P = (1, +∞)，Q = (2, +∞)。显然 Q ⫋ P（小范围推大范围：x > 2 一定满足 x > 1，反之不然）。
所以"∀x：p⇒q 成立"的方向要看小推向大：P ⫋ Q → p 是 q 的必要不充分条件。
"x > 1" 是 "x > 2" 的必要不充分条件
💡 记忆：谁的"许可范围"更大，谁就更"必要"。口袋里装 100 元（p，宽）是"能买 50 元书"（q，严）的必要不充分条件——钱多不一定买，但买书一定要钱够。

例 4【点集运算】 ★★

设 A = {(x, y) | y = x²}，B = {(x, y) | y = x}。求 A ∩ B。


点集交点 = 两条曲线的公共点：联立 y = x² 与 y = x → x² = x → x = 0 或 x = 1。
A ∩ B = {(0, 0), (1, 1)}
注意结果仍为点集（写成 (x,y) 坐标，而不是数）。

例 5【量词否定改写】 ★★★

写出下列命题的否定：


① p：∀x ∈ ℝ，x² + 2x + 1 ≥ 0
¬p：∃x ∈ ℝ，x² + 2x + 1 < 0（全称 → 存在，≥ 取反为 <）
② 若 q："∃x ∈ ℝ，x² − 6 = 0"（存在性命题），则
¬q：∀x ∈ ℝ，x² − 6 ≠ 0（存在 → 全称，等式取反为不等）
⚠ 易错：否定"≥"时必须同时翻转量词；只翻量词或只翻结论都不完整。

📝 章节练习题

1集合 {y | y = x², x ∈ {−1, 0, 1}} 等于____。
✅ B。代表元是 y（数），x 取遍 {−1,0,1} 时 y = x² 只能取 0 和 1，所以集合 = {0, 1}。
2满足 {1, 2} ⊆ A ⫋ {1, 2, 3} 的集合 A 的个数为____。
✅ A。A 必须包含 {1,2}，又必须是 {1,2,3} 的真子集（不能等于它），只有 A = {1, 2} 一个。
3设 A = {x | 1 ≤ x ≤ 3}，B = {x | x ≤ a}。若 A ∪ B = B，则 a 的取值范围是____。
✅ A。A ∪ B = B ⇔ A ⊆ B，数轴上 [1,3] 要落在 (−∞,a] 内，右端点须 a ≥ 3（等号成立：(−∞,3] ⊇ [1,3] ✓）。
4已知 U = {1, 2, 3, 4, 5}，A = {1, 2}，B = {2, 3}，则 ∁ᴜ(A ∪ B) = ____。
✅ A。A ∪ B = {1, 2, 3}，在 U 中取补得 {4, 5}。也可用德摩根律：∁ᴜA ∩ ∁ᴜB = {3,4,5} ∩ {1,4,5} = {4,5}。
5"x > 2" 是 "x² > 4" 的____条件。
✅ A。x > 2 ⇒ x² > 4 成立；x² > 4 ⇔ x < −2 或 x > 2，推不出 x > 2（还有 x < −2）。（2,+∞) ⫋ (−∞,−2)∪(2,+∞)，真子集 → 充分不必要。
6命题 p："存在 x ∈ ℝ，x² < 0"的否定是____。
✅ B。量词翻转 ∃→∀ 且结论取反 < → ≥，规范写法："对任意的 x ∈ ℝ，x² ≥ 0"。A 只是口语版（C 只翻结论、D 只翻量词，都不完整）。
7"A = B" 是 "A ∩ B = A" 的____条件。
✅ B。A = B ⇒ A ∩ B = A ✓；但 A ∩ B = A 只能得 A ⊆ B（如 A={1}, B={1,2}），推不出 A = B。所以是必要不充分条件。
8已知集合 A、B 非空。则"A ∩ B = A" 是 "A ⊆ B" 的____条件。
✅ C。正向：A ∩ B = A ⇒ A 的元素全在 B 中 ⇒ A ⊆ B；反向：A ⊆ B ⇒ A ∩ B = A。两个方向都成立 → 充要条件（这正是 1.3 节三组等价关系的第一条）。
